# Review Standards

对照项目的编码标准逐条检查 diff。

## 前置条件

review-init 已完成，你已知道 diff 命令和 standards 来源列表。

## 流程

### 1. 读取标准

逐个读取 standards 来源文件。提取每一条编码规则，区分：

- **工具强制规则**（eslint、biome、tsc 等已自动检查的）→ 跳过，不重复检查
- **人工规则**（AGENTS.md 中的约定、ADR 中的架构决策、CONTRIBUTING.md 中的流程要求）→ 逐条检查

### 2. 逐条检查 diff

对 diff 中的每个文件/hunk，检查是否违反人工规则。

每条发现引用标准来源（文件 + 具体规则）。区分：
- **硬性违反**：明确违反了文档化的规则
- **判断性建议**：可能违反规则精神但不是明确违反

### 3. 产出报告

**退出 → 提交 `show(final report)`，格式：**

```
【阶段】Review Standards
【检查规则数】N 条人工规则（跳过 M 条工具强制规则）
【硬性违反】
  - 文件:行号 — 违反了什么规则（引用标准来源:规则）
【判断性建议】
  - 文件:行号 — 可能的问题（引用标准来源:规则）
【结论】（总体评估）
```

无发现 → 明确报告"Standards 审查通过，未发现问题"。
