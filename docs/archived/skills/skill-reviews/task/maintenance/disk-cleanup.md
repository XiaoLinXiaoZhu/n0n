# disk-cleanup

> 来源：user skill | 激活：manual

## A. 类型组成

**Methodology**（主要）+ **Knowledge**（次要）。磁盘清理的分级方法论 + Windows 系统工具知识 + Bun Shell 避坑指南。

## B. 作用与核心思想

定义磁盘清理的标准化流程和安全规则。

三层内容：
1. **文件五级分类**——从"无信息价值可直接删除"到"影响稳定性禁止删除"的分级标准，每级有明确的处理策略
2. **清理工作流程**——Everything CLI 定位 → 五级分类 → Bun 脚本执行 → 等级 4 需确认
3. **知识参考**——NVIDIA 驱动目录处理、Bun Shell glob 避坑、Windows 系统工具路径

核心思想：**用分级标准消除清理决策的模糊性**。模型不需要"判断"哪些文件能删，只需要"分类"，分类结果直接决定处理方式。

## C. 与执行工具和 progress 的结合潜力

**中等结合**。清理工作流可以映射到工具：
- observe（Everything CLI 搜索、查看文件大小）
- reason（按五级标准分类）
- act（执行删除脚本）

与 progress 的结合潜力：等级 4 文件（用户数据）需要 progress(blocked) 请求确认，这已经隐含在"询问后删除"的规则中。如果将其显式化为 progress(blocked) 触发条件，会更清晰。
