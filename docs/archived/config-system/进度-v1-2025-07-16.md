## 注意事项

- `LLMConfigTOMLSchema` 字段名使用 snake_case（`api_key`、`base_url`、`thinking_budget_tokens`），对应 TOML 惯例
- `toProviderConfig` 负责 snake_case → camelCase 转换
- `config.ts` 仍保留 `ProviderConfig` 的 interface 风格 type 导出（向后兼容 `factory.ts` 等消费者）
- 不要忘记 `packages/llm/package.json` 可能需要添加 `@n0n/config` 依赖（如果 llm 需要导入 config 的类型）
