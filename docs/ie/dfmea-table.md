# DFMEA 完整表格

## 概览

- 覆盖 6 个功能 × 25 个子功能，共 32 条失效链（含 F1.6 新增）
- F1.6 来自 2025-07-27 的真实失效事件：设计者在完成 DFMEA 文档撰写后立即违反了其中 6 条规则
- 评分锚点见 `methodology.md`

## 评分规则

| 项 | 规则 |
|----|------|
| S（严重度） | 基于操作后果的固有属性。高 S（>=7）命中即停止/确认 |
| O（频度） | **关键判断：这是不是模型在没有结构性对抗时的默认行为？** 是 → O>=7 |
| D（探测度） | 模型读一遍自己的输出能发现吗？不能 → D>=7 |

## 核心前提

模型的默认行为是走捷径。这不是"偶尔疏忽"——是 LLM 训练分布的产物。

**2025-07-27 补充**：即使是 DFMEA 规则的设计者本人（Claude），在写完规则后的下一次交互中就违反了 F1.1/F1.2/F1.3/F1.4/F2.1/F2.2 共 6 条。这证明：(a) 训练分布偏差 > 文本规则，(b) "理解规则" ≠ "遵守规则"，(c) 需要系统级 enforcement 而非仅提示词文本。

## 关键发现

新增 F1.6 后，F1 有 4 条失效的 O×D = 72（并列最高），1 条 64。**整个 F1 功能群的 O×D 集中在 64-72。**

F1.6 的特殊性：它的 D=9（最高），因为模型天然认为自己"已经做对了"——它不会发现"我漏掉了上下文中的某条规则"。探测只能靠外部系统（agent loop compliance check）。这与 F1.1-F1.5 不同——那些可以通过自我追问来探测。F1.6 无法自测，必须外部强制。
